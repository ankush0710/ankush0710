## About

I am a full-stack developer with a strong foundation in the MERN stack, building responsive, performant and maintainable web applications. I now combine that engineering background with Generative AI, designing LLM-powered features such as retrieval-augmented generation (RAG) pipelines, agentic workflows and automation systems.

- Building production-minded web applications with React, Redux Toolkit, Next.js, Node.js and Express
- Creating APIs with Node.js/Express and FastAPI, backed by MySQL and MongoDB
- Developing LLM applications with LangChain and LangGraph, grounded in RAG over private data
- Automating business workflows end to end with n8n
- Fine-tuning open-source models efficiently using LoRA and QLoRA
